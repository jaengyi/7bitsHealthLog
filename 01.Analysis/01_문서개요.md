## 1.1 목적

본 문서는 개인 사용을 목적으로 하는 Android 운동기록 애플리케이션의 요구사항과 기능을 정의한다.
PT(퍼스널 트레이닝)를 통해 학습한 개별 동작을 체계적으로 기록·복기하고, 누적된 기록을 강도·볼륨 관점에서
분석하여 **점진적 과부하를 데이터로 관리**하는 것을 1차 목표로 한다.

## 1.4 용어 정의

| 용어 | 설명 |
|---|---|
| **1RM** | One Rep Max. 1회 수행 가능한 최대 중량. 본 앱에서는 실측이 아닌 세트 기록 기반 추정값(Epley 등)을 사용한다. |
| **볼륨 (Volume)** | Σ(중량 × 횟수). 수행한 총 물리적 작업량 지표. 웜업 세트는 집계에서 제외한다. |
| **강도 (Intensity)** | 해당 세트 중량 ÷ 추정 1RM × 100(%). 근력/근비대/근지속력 구간 판정에 사용한다. |
| **RPE / RIR** | RPE는 자각적 운동강도(1~10), RIR은 남은 반복 여유 횟수. 주관적 강도 지표. |
| **루틴 (Routine)** | 반복 수행하는 종목 묶음 템플릿. 실제 기록(일지)과 분리되어 관리된다. |
| **분할 (Split)** | 복수 루틴을 요일 또는 순환 순서로 배정한 주간 운동 구성 (예: 3분할, 5분할). |
| **점진적 과부하** | 일정 조건 충족 시 목표 중량·횟수를 단계적으로 증가시켜 자극을 유지하는 훈련 원칙. |
| **드랍 세트** | 목표 횟수 실패 후 중량을 즉시 낮춰 이어서 수행하는 세트. |
| **슈퍼세트** | 2개 이상 종목을 휴식 없이 연속 수행하는 세트 구성. |
| **눈바디** | 체중계 수치가 아닌 외형 변화를 사진으로 비교·확인하는 기록 방식. |
| **Tombstone** | 동기화 환경에서 삭제 사실을 전파하기 위해 남기는 논리 삭제 기록. |
| **LWW** | Last-Write-Wins. 최종 수정시각이 늦은 쪽을 채택하는 동기화 충돌 해소 전략. |

## 1.5 릴리즈 전략 요약

| 릴리즈 | 성격 | 핵심 내용 |
|---|---|---|
| **Phase 1 (MVP)** | 핵심 기록 루프 + 종목 가이드 | 종목 라이브러리·검색, **종목 상세·자세 가이드(설명·이미지·영상)**, 운동일지 CRUD, 세트 입력, 프리필, 운동 수행 모드, 휴식 타이머, 루틴 실행, 월간 캘린더, PT 학습 노트, 로컬 우선 저장 |
| **Phase 2** | 분석 · 동기화 | 1RM 추정, %1RM 강도 분석, 성장 그래프, 주간·월간 리포트, PR 관리, 메모 통합 검색, 체성분 기록, 개인 서버 동기화, 백업/복구, 원판·1RM 계산기, 유산소 기록, 분할 프로그램 |
| **Phase 3** | 식단 · 워치 · 확장 | 식단 기록·영양 집계, 눈바디 사진, 밸런스 분석, 주기화·점진적 과부하 자동 제안, 인터벌 타이머, Wear OS·Health Connect 연동, 다국어 |
