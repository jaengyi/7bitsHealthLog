## ID 체계

### 접두어

| 유형 | 접두어 | 예시 |
|---|---|---|
| 요구사항 | `REQ-` | `REQ-WRK-003` |
| 기능 | `FN-` | `FN-WRK-009` |
| 화면 | `SCR-` | `SCR-WRK-002` |
| 엔티티 | `ENT-` | `ENT-010` |

### 도메인 코드

| 코드 | 도메인 | 코드 | 도메인 |
|---|---|---|---|
| `CMN` | 공통/계정 | `RPT` | 분석/리포트 |
| `EXR` | 운동종목 | `BDY` | 신체데이터 |
| `WRK` | 운동기록 | `DIE` | 식단 |
| `RTN` | 루틴/프로그램 | `TOL` | 보조도구 |
| `CAL` | 캘린더 | `DAT` | 데이터관리 |
| | | `NFR` | 비기능 |

### 추적성 (Traceability)

```
REQ-xxx-nnn  ──분해──▶  FN-xxx-nnn  ──구현──▶  SCR-xxx-nnn
                            │
                            └──참조──▶  ENT-nnn
```

- 요구사항 → 기능: 요구사항정의서의 `관련 기능ID` 컬럼
- 기능 → 요구사항: 기능정의서의 `관련 요구사항ID` 컬럼
- 기능 → 화면: 기능정의서의 `관련 화면ID` 컬럼 (`-` 는 화면 없는 백그라운드 처리)
- 화면 → 기능: 화면목록의 `관련 기능ID` 컬럼
