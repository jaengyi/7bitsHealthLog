# 기능정의서

**개인용 운동기록 애플리케이션 (가칭 MyFit) · v1.1**

> 본 문서는 `01.Analysis/운동기록앱_요구사항정의서_기능정의서_v1.1.xlsx` 의 **기능정의서** 시트를 Markdown으로 옮긴 산출물이다.
> 원본 셀 내용은 가감 없이 그대로 반영하였으며, 가독성을 위해 분류 단위로 절을 나누었다.


- 요구사항정의서의 각 요구사항을 **구현 단위 기능**으로 분해한 목록이다.
- 기능별로 입력(Input) · 처리(Process) · 출력(Output)을 정의하여 설계 단계의 입력물로 사용한다.
- **우선순위**: 상 / 중 / 하 · **릴리즈**: Phase 1(MVP) → Phase 2 → Phase 3
- **총 161건** (Phase 1 68건 / Phase 2 57건 / Phase 3 36건)
