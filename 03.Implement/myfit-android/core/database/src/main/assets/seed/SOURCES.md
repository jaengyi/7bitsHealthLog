### Unlicense를 선택한 이유

검토한 대안과 비교했을 때 조건이 가장 단순하다.

| 소스 | 라이선스 | 판단 |
|---|---|---|
| **free-exercise-db** | **Unlicense (퍼블릭 도메인)** | ✅ 채택 — 출처 표시 의무·ShareAlike 전염 모두 없음 |
| wger | CC BY-SA 4.0 (항목별 상이) | ⚠️ 배포 시 동일 라이선스 의무 |
| Everkinetic | CC BY-SA 3.0 | ⚠️ 동일 |
| exercises-dataset | 텍스트 MIT, **미디어 © Gym visual** | ❌ 미디어 별도 유료 라이선스 필요 |
| ExRx.net | 상용 저작권 | ❌ 사용 불가 |

퍼블릭 도메인이므로 법적 의무는 없으나, **출처를 밝히는 것이 온당하므로 본 문서로 기록**한다.

## body_parts.json

전량 자체 작성. 국내 통용 부위 구분(가슴/등/어깨/팔/전완/복근/허리/둔근/하체/종아리/전신)을 따른다.

## 미해결 — 한글 수행 방법·주의사항

현재 `description` / `caution` 은 **비어 있다**.

- 원본의 `instructions` 는 영문이며, 기계 번역으로는 헬스장 통용 표현을 맞추기 어렵다.
- REQ-NFR-009 상 자체 작성이 원칙이므로, 한글 설명은 **직접 작성해 채운다.**
- 화면에서는 설명이 없으면 해당 영역을 표시하지 않는다(빈 상태 처리).

## 미해결 — 자세 가이드 이미지

`guideImageAsset` 도 **비어 있다**. 원본은 종목당 1~2장의 사진(JPG)을 퍼블릭 도메인으로 제공하며
선별한 219종에 대해 **438장**이 존재한다. 도입 시 설계서 규격(WebP q80, 최대 720px, 종목당 30KB 이하,
총 9MB 예산)에 맞춰 변환해야 한다. 변환 대상 목록은 별도 매니페스트로 관리한다.
