## 확정 기술 스택

| 영역 | 선정 |
|---|---|
| **앱** | Kotlin · Jetpack Compose · Clean Architecture(3계층) + MVVM(UDF) |
| **모듈 구조** | **멀티모듈** — `:app` / `:core:*` 7종 / `:feature:*` 9종 / `:wear` / `build-logic` |
| **로컬 저장** | Room (SSoT) · DataStore · 앱 전용 내부 저장소 |
| **DI / 비동기** | Hilt · Coroutines + Flow |
| **백그라운드** | WorkManager(동기화·백업·알림) · Foreground Service(휴식 타이머) |
| **통신** | Retrofit + OkHttp + kotlinx.serialization |
| **백엔드** | **Spring Boot 3 + Kotlin** · PostgreSQL 16 · Flyway |
| **인프라** | Ubuntu · Docker Compose · nginx + Let's Encrypt (`7bits.mooo.com`) |
| **지원 범위** | minSdk 26 (Android 8.0+) · 세로 고정 · 화면 폭 360dp+ · 다크 기본 |

## 설계 핵심 원칙

| # | 원칙 | 요지 |
|---|---|---|
| P1 | **Local-First** | Room이 단일 진실 공급원. 서버는 백업·동기화 채널일 뿐 |
| P2 | **Offline-Complete** | 헬스장 지하에서도 기록·조회·분석 전 기능 동작. 동기화 실패는 무음 처리 |
| P3 | **의존성 역전** | `:core:domain` 은 순수 Kotlin(JVM 모듈) — `import android.*` 자체가 컴파일 에러 |
| P4 | **단방향 데이터 흐름** | 상태는 ViewModel이 소유, `StateFlow` 하나로 노출 |
| P5 | **즉시 영속** | 저장 버튼 없음. 입력 즉시 debounce 300ms 후 Room upsert |
| P6 | **계산은 Domain에서** | 1RM·볼륨·강도·원판은 전부 순수 함수 → 단위 테스트 100% |
| P7 | **표시 시점 단위 변환** | 저장은 항상 SI(kg/cm/km) |
| P8 | **확장 가능한 세트 스키마** | 기록유형 5종을 nullable 컬럼으로 수용 |

## 설계 단계에서 확정한 주요 결정

| # | 결정 | 근거 |
|---|---|---|
| 1 | 백엔드를 **Spring Boot 3 + Kotlin** 으로 선정 | 앱과 언어 통일 → DTO·검증 규칙 재사용, JPA/Flyway 성숙도 |
| 2 | **멀티모듈** 구조 채택 | `:core:domain` 을 JVM 모듈로 두어 계층 위반을 컴파일 단계에서 차단 |
| 3 | 서버 API를 **동기화 Push/Pull 2개**로 집약 | 도메인별 CRUD 대비 왕복·배터리 소모 최소화. `EntityRegistry` 로 엔티티 추가 비용 제거 |
| 4 | 논리 엔티티 24개 → **물리 테이블 30개** | 주기화·루틴버전·식단세트·FTS 등 구현 테이블 6개 추가 (04 §7) |
| 5 | 세트 입력에 **전용 숫자 키패드** 사용 | 시스템 키보드는 세트 표를 가리고 3터치 입력을 방해 (06 §3.11) |
| 6 | 신체 사진은 **동기화 대상 제외** | 개인 서버 용량·전송 비용. 백업 파일로 기기 이전 (04 §3.20) |
| 7 | `SCHEDULE_EXACT_ALARM` **미사용** | 운동 리마인더는 분 단위 정밀도 불필요 → 권한 승인 절차 회피 (02 §5.1) |
| 8 | 충돌 시 **삭제 우선** | "지웠는데 되살아남"의 체감 손상이 더 크다 (07 §15) |
| 9 | **v1.1** 자세 가이드를 **이미지 내장 + 영상 외부 링크** 하이브리드로 | 오프라인 원칙(REQ-NFR-003)과 저작권(REQ-NFR-009)·APK 예산을 동시에 만족. 설명·이미지는 오프라인 보장, 영상만 온라인 부가 기능 (02 §5.3, 06 §3.8) |
| 10 | **v1.1** 영상 재생에 서드파티 플레이어 라이브러리 미도입 | Android 내장 `WebView` + YouTube IFrame Player로 충분. 의존성·APK 증가 없음 (02 §5.3) |
| 11 | **v1.1** 종목 선택 중 상세를 **바텀시트**로 노출 | 전체 화면 전환 시 선택 상태·스크롤이 끊김. "확인 → 닫기 → 계속 선택" 흐름 유지 (06 §3.7) |
