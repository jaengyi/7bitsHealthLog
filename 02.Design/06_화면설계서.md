# 화면 설계서

**개인용 운동기록 애플리케이션 (가칭) MyFit · v1.1**

> 관련 요구사항: `REQ-NFR-002`(한손 조작·터치 편의성), `REQ-NFR-005`(단말 지원), `REQ-CMN-005`(다크모드), `REQ-NFR-001`(응답 성능)
> 상위 문서: [01.Analysis/04_화면목록.md](../01.Analysis/04_화면목록.md) (45개 화면 목록)

> **작성 범위**: Phase 1(MVP) **17개 화면**은 **와이어프레임 + 인터랙션 + UiState** 까지 상세 설계하고,
> Phase 2/3의 28개 화면은 **구성요소·인터랙션 명세**로 정의한다. Phase 2/3 와이어프레임은 해당 Phase 착수 시 본 문서에 증분 작성한다.
>
> **v1.1 변경**: 종목 자세 가이드 요구사항(`REQ-EXR-003`) 반영으로 `SCR-EXR-002`(종목 상세·자세 가이드)가
> Phase 2 → **Phase 1** 로 상향되었고, `SCR-EXR-001`(종목 선택)에 **상세 미리보기 바텀시트**(`FN-EXR-018`)가 추가되었다.

## 1. 공통 UI 설계

### 1.1 디자인 원칙 (REQ-NFR-002)

| # | 원칙 | 구체 기준 |
|---|---|---|
| U1 | **한손 조작** | 주요 조작 요소(세트 추가, 완료 체크, ± 버튼, FAB)는 **화면 하단 1/3 영역**에 배치. 상단은 정보 표시 전용 |
| U2 | **터치 타겟 48dp** | 모든 탭 가능 요소 최소 48×48dp. 세트 표의 ± 버튼은 **56dp** (땀·장갑 착용 고려) |
| U3 | **3터치 이내 입력** | 세트 1건 입력 = 중량 탭 → 값 입력 → 완료. 프리필로 대부분 **0~1터치** (REQ-WRK-003) |
| U4 | **파괴적 동작 확인** | 삭제·초기화는 확인 다이얼로그 또는 스와이프+Undo 스낵바 |
| U5 | **다크 우선** | 기본 테마 다크(헬스장 조명). 대비율 WCAG AA(4.5:1) 이상 |
| U6 | **읽기 거리 고려** | 운동 중 화면은 팔 길이 거리에서 읽힘 — 세트 정보 폰트 20sp 이상 |
| U7 | **오프라인 무표시** | 네트워크 상태·동기화 실패를 기본 UI에 노출하지 않음 (설정 화면에서만) |

| 이벤트 | 처리 | 결과 |
|---|---|---|
| Google/Kakao 탭 | OAuth → `POST /auth/social-login` → 토큰 저장 | 온보딩 미완료면 `SCR-CMN-006`, 아니면 `SCR-CMN-001` |
