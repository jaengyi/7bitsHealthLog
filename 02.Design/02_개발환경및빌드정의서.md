**APK 크기 구성 예산** (REQ-EXR-003 자세 가이드 반영)

| 구성 | 예산 | 비고 |
|---|---:|---|
| 코드 + 라이브러리 (R8 후) | ~12MB | Compose·Room·Retrofit·Vico |
| 내장 종목 시드 DB | ~2MB | 300종 + 부위 매핑 + 프리셋 |
| **자세 가이드 이미지** | **~9MB** | WebP q80, 최대 720px, 종목당 30KB × 300종 (FN-EXR-016) |
| 아이콘·폰트·기타 리소스 | ~3MB | |
| **합계** | **~26MB** | 예산 30MB 대비 여유 4MB |

> 이미지 총량이 예산을 초과하면 ① WebP quality 하향 ② 상위 사용빈도 종목만 내장하고 나머지는 텍스트 설명만 제공
> ③ Play Asset Delivery 분리 순으로 대응한다. **영상은 내장하지 않으므로 크기에 영향이 없다.**

### 2.4 버전 확정 근거 — 제약 사슬 (2026-07-30)

착수 시점의 최신 라인은 **AGP 9.3.1 + compileSdk 37** 이지만 채택하지 않았다.
각 구성요소의 요구 버전은 아래처럼 **연쇄로 묶여 있어**, 하나를 올리면 나머지가 전부 끌려온다.

```
로컬 SDK 보유 범위 (android-34 / 36 / 36.1 — 37 미설치)
        ↓
compileSdk 36
        ↓
androidx.core 1.18.0 · lifecycle 2.10.0 · androidx.hilt 1.3.0
   (각 최신판 1.19.0 / 2.11.0 / 1.4.0 은 AAR 메타데이터에 minCompileSdk=37)
        ↓
AGP 8.13.2  →  Hilt 2.58        (2.59+ 는 AGP 9.0.0 이상 요구)
        ↓
Gradle 8.13                     (AGP 9.3.1 은 Gradle 9.5.0 이상 요구)
```

**근거는 전부 아티팩트에서 직접 확인**하였다(추정 아님).

| 확인 대상 | 확인 방법 | 결과 |
|---|---|---|
| Hilt 최소 AGP | `HiltPluginEnvironment.class` 내 상수 | 2.59+ → `9.0.0` / 2.58 → `8.4.0` |
| AGP 최소 Gradle | `VersionCheckPlugin.class` 내 상수 | AGP 9.3.1 → `9.5.0` |
| 라이브러리 최소 compileSdk | AAR 의 `aar-metadata.properties` `minCompileSdk` | core 1.19.0 → `37` 등 |

**AGP 9 이관 시 필요한 작업** (별도 과제로 분리)

1. SDK 플랫폼 **android-37** 설치 — 현재 `cmdline-tools` 미설치 상태
2. Gradle **9.5.0** 이상으로 상향
3. **AGP 9 의 Kotlin 내장 지원 이관** — `org.jetbrains.kotlin.android` 플러그인 적용이 금지되어
   KSP · Compose Compiler · Hilt 의 적용 경로를 전부 재구성해야 한다 (이관 비용의 대부분)
4. AGP 9 DSL 변경 대응 — `CommonExtension` 이 비제네릭이 되고 `defaultConfig { }` 등 람다 설정
   메서드가 제거된다. **본 저장소의 Convention Plugin 은 이미 프로퍼티 접근 방식으로 작성**되어
   `CommonExtension` 타입 인자만 제거하면 된다

> 버전 상수가 `libs.versions.toml` 한 곳에만 있으므로, 실제로 AGP 9 ↔ 8 을 왕복 검증할 때
> 수정 범위는 **버전 2~3줄 + Convention Plugin** 으로 한정되었다.

| Build Type | applicationIdSuffix | 디버깅 | R8 | 로깅 | API Base URL |
|---|---|---|---|---|---|
| `debug` | `.debug` | O | X | 전체 | `https://dev.7bits.mooo.com/api/v1/` |

### 4.3 Convention Plugin (`build-logic`)

모듈이 Phase 1 기준 13개(최종 20개 예정)이므로 공통 설정은 `build-logic` 복합 빌드로 일원화한다.

| 플러그인 ID | 구현 클래스 | 적용 대상 | 내용 |
|---|---|---|---|
| `myfit.android.application` | `AndroidApplicationConventionPlugin` | `:app` | compileSdk/minSdk/targetSdk, Java17, desugaring |
| `myfit.android.library` | `AndroidLibraryConventionPlugin` | `:core:*` (Android) | 라이브러리 공통 + **테스트 의존성 주입**(JUnit/Truth/MockK/Turbine) |
| `myfit.android.library.compose` | `AndroidLibraryComposeConventionPlugin` | Compose 사용 모듈 | Compose 플러그인 + BOM |
| `myfit.android.feature` | `AndroidFeatureConventionPlugin` | `:feature:*` | library.compose + hilt + core 의존 + 네비게이션·직렬화 |
| `myfit.android.hilt` | `AndroidHiltConventionPlugin` | DI 사용 모듈 | KSP + Hilt |
| `myfit.android.room` | `AndroidRoomConventionPlugin` | `:core:database` | Room + KSP + `room.schemaLocation` |
| `myfit.jvm.library` | `JvmLibraryConventionPlugin` | `:core:common`, `:core:domain` | **순수 Kotlin JVM** (Android 플러그인 미적용 → 안드로이드 의존 원천 차단) |

> 초안의 `myfit.android.test` 는 별도 플러그인으로 두지 않고 `library` / `jvm.library` 에 흡수했다.
> 테스트 의존성만을 위해 모든 모듈에 플러그인을 한 줄 더 적는 것은 실익이 없다.
> 대신 초안에 없던 `myfit.android.feature` 를 추가하여 feature 모듈의 반복 설정(핵심 4줄 + 의존 5종)을 제거했다.

> `:core:domain` 에 `myfit.jvm.library` 만 적용하는 것이 **P3(의존성 역전) 원칙을 컴파일 단계에서 강제하는 장치**다.
> 이 모듈에서는 `import android.*` 자체가 컴파일 에러가 된다.

### 4.4 R8 / ProGuard 규칙 (`proguard-rules.pro`)

```proguard

-dontnote kotlinx.serialization.**
-keepclassmembers class com.sevenbits.myfit.**$$serializer { *; }
-keepclasseswithmembers class com.sevenbits.myfit.** {

# ── Room ──────────────────────────────────────────────

-dontwarn okhttp3.**
-dontwarn okio.**
```

### 5.3 자세 영상 재생 구성 (FN-EXR-017)

영상 파일을 앱에 내장하거나 서버에 저장하지 않고, **외부 영상 서비스의 공식 임베드 플레이어**만 사용한다(REQ-NFR-009).

| 항목 | 설계 |
|---|---|
| 재생 방식 | **YouTube IFrame Player API** 를 `WebView` 로 로드 (`videoId`, `start` 파라미터) |
| 신규 의존성 | **없음** — Android 내장 `WebView` 사용 (서드파티 플레이어 라이브러리 미도입) |
| 실패 대체 | 로드 실패 시 `Intent(ACTION_VIEW, url)` → YouTube 앱 / 브라우저 실행 |
| 오프라인 | 재생 영역을 안내 문구로 대체. **설명·자세 이미지는 정상 표시** (REQ-NFR-003) |
| 추가 권한 | 없음 (`INTERNET` 으로 충분) |

```kotlin
// WebView 보안 설정 — 임베드 재생에 필요한 최소 권한만 허용
webView.settings.apply {
    javaScriptEnabled = true              // IFrame Player 필수
    domStorageEnabled = true
    mediaPlaybackRequiresUserGesture = true   // 자동 재생 차단
    allowFileAccess = false                   // 로컬 파일 접근 차단
    allowContentAccess = false
    cacheMode = WebSettings.LOAD_DEFAULT
}
webView.webViewClient = object : WebViewClient() {
    // 앱 내 WebView 는 YouTube 임베드 도메인으로만 한정, 그 외 링크는 외부 브라우저로
    override fun shouldOverrideUrlLoading(v: WebView, req: WebResourceRequest): Boolean {
        val host = req.url.host.orEmpty()
        return if (host.endsWith("youtube.com") || host.endsWith("youtube-nocookie.com")) false
        else { context.startActivity(Intent(Intent.ACTION_VIEW, req.url)); true }
    }
}
```

| Manifest 설정 | 값 | 사유 |
|---|---|---|
| `android:usesCleartextTraffic` | **미선언(=false)** | HTTPS 임베드만 허용 (REQ-NFR-004) |
| `WebView` 하드웨어 가속 | 기본 활성 | 영상 재생 성능 |

> **`youtube-nocookie.com` 임베드 도메인을 우선 사용**한다. 추적 쿠키를 최소화하여 개인 사용 목적에 부합시킨다.

## 7. 서버 개발·운영 환경 (REQ-NFR-010)

### 7.1 Docker Compose 구성

```yaml
# 05.Deploy/docker-compose.yml
services:
  db:
    image: postgres:16-alpine
    container_name: myfit-db
    restart: unless-stopped
    environment:
      POSTGRES_DB: myfit
      POSTGRES_USER: ${DB_USER}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
      TZ: Asia/Seoul
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./backup:/backup
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${DB_USER} -d myfit"]
      interval: 10s
      retries: 5
    networks: [myfit-net]
    # 외부 포트 미노출 — API 컨테이너만 접근

  api:
    image: myfit-api:${API_VERSION:-latest}
    container_name: myfit-api
    restart: unless-stopped
    depends_on:
      db: { condition: service_healthy }
    environment:
      SPRING_PROFILES_ACTIVE: prod
      SPRING_DATASOURCE_URL: jdbc:postgresql://db:5432/myfit
      SPRING_DATASOURCE_USERNAME: ${DB_USER}
      SPRING_DATASOURCE_PASSWORD: ${DB_PASSWORD}
      MYFIT_JWT_SECRET: ${JWT_SECRET}
      MYFIT_JWT_ACCESS_TTL: 1800          # 30분
      MYFIT_JWT_REFRESH_TTL: 2592000      # 30일
      JAVA_TOOL_OPTIONS: "-Xms128m -Xmx512m"
      TZ: Asia/Seoul
    ports: ["127.0.0.1:8080:8080"]        # 로컬 바인딩 — nginx만 접근
    healthcheck:
      test: ["CMD", "wget", "-qO-", "http://localhost:8080/actuator/health"]
      interval: 30s
    networks: [myfit-net]

  backup:
    image: postgres:16-alpine
    container_name: myfit-backup
    restart: unless-stopped
    depends_on: [db]
    environment:
      PGPASSWORD: ${DB_PASSWORD}
    volumes:
      - ./backup:/backup
    entrypoint: >
      sh -c 'while true; do
        pg_dump -h db -U ${DB_USER} -d myfit -Fc
          -f /backup/myfit_$$(date +%Y%m%d).dump;
        find /backup -name "myfit_*.dump" -mtime +14 -delete;
        sleep 86400;
      done'
    networks: [myfit-net]

volumes:
  pgdata:
networks:
  myfit-net:
```

> **일 1회 자동 덤프 + 14일 보관**으로 REQ-NFR-010을 충족한다. 덤프 파일은 `./backup` 에 적재되며,
> 별도 원격 스토리지 동기화(rsync/rclone)는 운영 정책에 따라 추가한다.

```nginx
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }
}
server {
    listen 80;
    server_name 7bits.mooo.com;
    return 301 https://$host$request_uri;
}
```

### 7.3 서버 리소스 산정
