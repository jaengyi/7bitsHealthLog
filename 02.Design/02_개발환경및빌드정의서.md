> ⚠️ **버전 표기 기준**: 본 문서의 버전은 **2026-07 기준 안정 버전을 가정한 baseline**이다.

### 2.3 성능 예산

| 지표 | 목표 | 측정 방법 |
|---|---|---|
| 콜드 스타트 (TTID) | 2.0초 이내 | Macrobenchmark |
| 운동일지 화면 진입 | **1.0초 이내** (REQ-NFR-001) | Macrobenchmark, 30,000세트 시드 데이터 기준 |
| 세트 입력 반영 | **100ms 이내** | 프레임 드롭 계측(JankStats) |
| 종목 검색 결과 | **300ms 이내** | DAO 쿼리 계측 로그 |
| APK 크기 | 30MB 이내 (내장 종목 DB + 자세 가이드 이미지 포함) | R8 + 리소스 축소 |

**APK 크기 구성 예산** (REQ-EXR-003 자세 가이드 반영)

| 구성 | 예산 | 비고 |
|---|---:|---|
| 코드 + 라이브러리 (R8 후) | ~12MB | Compose·Room·Retrofit·Vico |
| 내장 종목 시드 DB | ~2MB | 300종 + 부위 매핑 + 프리셋 |
| **자세 가이드 이미지** | **~9MB** | WebP q80, 최대 720px, 종목당 30KB × 300종 (FN-EXR-016) |
| 아이콘·폰트·기타 리소스 | ~3MB | |
| **합계** | **~26MB** | 예산 30MB 대비 여유 4MB |

> 이미지 총량이 예산을 초과하면 ① WebP quality 하향 ② 상위 사용빈도 종목만 내장하고 나머지는 텍스트 설명만 제공
> ③ Play Asset Delivery 분리 순으로 대응한다. **영상은 내장하지 않으므로 크기에 영향이 없다.**

### 3.1 라이브러리 선정 사유

| 라이브러리 | 용도 | 대안 대비 선정 사유 |

| Room + **KSP** | 로컬 DB | KAPT 대비 빌드 속도 우위. `exportSchema` 로 마이그레이션 검증 가능 |
| kotlinx.serialization | JSON | Gson/Moshi 대비 리플렉션 없음 → R8 규칙 단순, 백업 JSON에도 동일 사용 |

### 4.3 Convention Plugin (`build-logic`)

모듈이 15개 이상이므로 공통 설정은 `build-logic` 복합 빌드로 일원화한다.

| 플러그인 ID | 적용 대상 | 내용 |
|---|---|---|
| `myfit.android.application` | `:app` | compileSdk/minSdk, Java17, desugaring, buildTypes |
| `myfit.android.library` | `:core:*`, `:feature:*` (Android) | 라이브러리 공통 설정 |
| `myfit.android.library.compose` | `:core:ui`, `:core:designsystem`, `:feature:*` | Compose 플러그인 + BOM |
| `myfit.android.hilt` | Hilt 사용 모듈 | Hilt 플러그인 + KSP compiler |
| `myfit.android.room` | `:core:database` | Room + KSP + schemaLocation |
| `myfit.jvm.library` | `:core:domain` | **순수 Kotlin JVM** (Android 플러그인 미적용 → 안드로이드 의존 원천 차단) |
| `myfit.android.test` | 전 모듈 | JUnit/MockK/Turbine/Truth 공통 주입 |

> `:core:domain` 에 `myfit.jvm.library` 만 적용하는 것이 **P3(의존성 역전) 원칙을 컴파일 단계에서 강제하는 장치**다.
> 이 모듈에서는 `import android.*` 자체가 컴파일 에러가 된다.

### 4.4 R8 / ProGuard 규칙 (`proguard-rules.pro`)

```proguard
# ── kotlinx.serialization ─────────────────────────────
-keepattributes *Annotation*, InnerClasses
-dontnote kotlinx.serialization.**
-keepclassmembers class com.sevenbits.myfit.**$$serializer { *; }
-keepclasseswithmembers class com.sevenbits.myfit.** {
    kotlinx.serialization.KSerializer serializer(...);
}

# ── Room ──────────────────────────────────────────────
-keep class * extends androidx.room.RoomDatabase
-dontwarn androidx.room.paging.**

# ── Retrofit / OkHttp ─────────────────────────────────
-keepattributes Signature, Exceptions
-dontwarn okhttp3.**
-dontwarn okio.**

# ── 백업 JSON DTO는 필드명이 계약이므로 난독화 제외 ─────
-keep class com.sevenbits.myfit.core.data.backup.model.** { *; }

# ── 크래시 로그 가독성 ─────────────────────────────────
-keepattributes SourceFile, LineNumberTable
-renamesourcefileattribute SourceFile
```

> **주의**: 백업 JSON DTO(`FN-DAT-006/007`)는 필드명이 파일 포맷 계약이다. 난독화되면 구버전 백업 파일을 복구할 수 없으므로 반드시 `-keep` 한다.

| `ACCESS_NETWORK_STATE` | 전체 | WorkManager 네트워크 제약 판정, **자세 영상 재생 가능 여부 판정** | FN-DAT-005, FN-EXR-017 | 불필요 |
| `POST_NOTIFICATIONS` | **33+** | 휴식 타이머·운동 알림 표시 | FN-TOL-004, FN-TOL-011 | **필요** |
| `FOREGROUND_SERVICE` | 28+ | 휴식 타이머 서비스 | FN-TOL-001 | 불필요 |
| `FOREGROUND_SERVICE_HEALTH` | **34+** | FGS 타입 명시(운동 세션 추적) | FN-TOL-004 | 불필요 |
| `VIBRATE` | 전체 | 타이머 종료 진동 | FN-TOL-005 | 불필요 |
| `WAKE_LOCK` | 전체 | 타이머 정확도 보조 | FN-TOL-004 | 불필요 |
| `CAMERA` | 전체 | 눈바디·식단 사진 직접 촬영 | FN-BDY-005, FN-DIE-012 | **필요** (Phase 3, 선택 기능) |
| `health.READ_*` / `WRITE_*` | Health Connect | 체중·운동세션 읽기/쓰기 | FN-TOL-016~017 | **필요** (Phase 3) |

**의도적으로 선언하지 않는 권한**

| 미선언 권한 | 대체 수단 | 사유 |
|---|---|---|
| `READ_MEDIA_IMAGES` / `READ_EXTERNAL_STORAGE` | **Photo Picker** (`ActivityResultContracts.PickVisualMedia`) | 갤러리 선택에 권한 불필요. 최소 권한 원칙 |
| `WRITE_EXTERNAL_STORAGE` | **SAF** (`CreateDocument`) | 백업 파일 저장에 권한 불필요 |
| `SCHEDULE_EXACT_ALARM` | WorkManager / `setAndAllowWhileIdle` | 운동 리마인더는 분 단위 정밀도가 불필요. API 33+ 사용자 승인 절차 회피 |

### 5.3 자세 영상 재생 구성 (FN-EXR-017)

영상 파일을 앱에 내장하거나 서버에 저장하지 않고, **외부 영상 서비스의 공식 임베드 플레이어**만 사용한다(REQ-NFR-009).

| 항목 | 설계 |
|---|---|
| 재생 방식 | **YouTube IFrame Player API** 를 `WebView` 로 로드 (`videoId`, `start` 파라미터) |
| 신규 의존성 | **없음** — Android 내장 `WebView` 사용 (서드파티 플레이어 라이브러리 미도입) |
| 실패 대체 | 로드 실패 시 `Intent(ACTION_VIEW, url)` → YouTube 앱 / 브라우저 실행 |
| 오프라인 | 재생 영역을 안내 문구로 대체. **설명·자세 이미지는 정상 표시** (REQ-NFR-003) |
| 추가 권한 | 없음 (`INTERNET` 으로 충분) |

```kotlin
// WebView 보안 설정 — 임베드 재생에 필요한 최소 권한만 허용
webView.settings.apply {
    javaScriptEnabled = true              // IFrame Player 필수
    domStorageEnabled = true
    mediaPlaybackRequiresUserGesture = true   // 자동 재생 차단
    allowFileAccess = false                   // 로컬 파일 접근 차단
    allowContentAccess = false
    cacheMode = WebSettings.LOAD_DEFAULT
}
webView.webViewClient = object : WebViewClient() {
    // 앱 내 WebView 는 YouTube 임베드 도메인으로만 한정, 그 외 링크는 외부 브라우저로
    override fun shouldOverrideUrlLoading(v: WebView, req: WebResourceRequest): Boolean {
        val host = req.url.host.orEmpty()
        return if (host.endsWith("youtube.com") || host.endsWith("youtube-nocookie.com")) false
        else { context.startActivity(Intent(Intent.ACTION_VIEW, req.url)); true }
    }
}
```

| Manifest 설정 | 값 | 사유 |
|---|---|---|
| `android:usesCleartextTraffic` | **미선언(=false)** | HTTPS 임베드만 허용 (REQ-NFR-004) |
| `WebView` 하드웨어 가속 | 기본 활성 | 영상 재생 성능 |

> **`youtube-nocookie.com` 임베드 도메인을 우선 사용**한다. 추적 쿠키를 최소화하여 개인 사용 목적에 부합시킨다.

## 7. 서버 개발·운영 환경 (REQ-NFR-010)

### 7.1 Docker Compose 구성

```yaml
# 05.Deploy/docker-compose.yml
services:
  db:
    image: postgres:16-alpine
    container_name: myfit-db
    restart: unless-stopped
    environment:
      POSTGRES_DB: myfit
      POSTGRES_USER: ${DB_USER}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
      TZ: Asia/Seoul
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./backup:/backup
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${DB_USER} -d myfit"]
      interval: 10s
      retries: 5
    networks: [myfit-net]
    # 외부 포트 미노출 — API 컨테이너만 접근

  api:
    image: myfit-api:${API_VERSION:-latest}
    container_name: myfit-api
    restart: unless-stopped
    depends_on:
      db: { condition: service_healthy }
    environment:
      SPRING_PROFILES_ACTIVE: prod
      SPRING_DATASOURCE_URL: jdbc:postgresql://db:5432/myfit
      SPRING_DATASOURCE_USERNAME: ${DB_USER}
      SPRING_DATASOURCE_PASSWORD: ${DB_PASSWORD}
      MYFIT_JWT_SECRET: ${JWT_SECRET}
      MYFIT_JWT_ACCESS_TTL: 1800          # 30분
      MYFIT_JWT_REFRESH_TTL: 2592000      # 30일
      JAVA_TOOL_OPTIONS: "-Xms128m -Xmx512m"
      TZ: Asia/Seoul
    ports: ["127.0.0.1:8080:8080"]        # 로컬 바인딩 — nginx만 접근
    healthcheck:
      test: ["CMD", "wget", "-qO-", "http://localhost:8080/actuator/health"]
      interval: 30s
    networks: [myfit-net]

  backup:
    image: postgres:16-alpine
    container_name: myfit-backup
    restart: unless-stopped
    depends_on: [db]
    environment:
      PGPASSWORD: ${DB_PASSWORD}
    volumes:
      - ./backup:/backup
    entrypoint: >
      sh -c 'while true; do
        pg_dump -h db -U ${DB_USER} -d myfit -Fc
          -f /backup/myfit_$$(date +%Y%m%d).dump;
        find /backup -name "myfit_*.dump" -mtime +14 -delete;
        sleep 86400;
      done'
    networks: [myfit-net]

volumes:
  pgdata:
networks:
  myfit-net:
```

> **일 1회 자동 덤프 + 14일 보관**으로 REQ-NFR-010을 충족한다. 덤프 파일은 `./backup` 에 적재되며,
> 별도 원격 스토리지 동기화(rsync/rclone)는 운영 정책에 따라 추가한다.

### 7.2 nginx 리버스 프록시

```nginx
server {
    listen 443 ssl http2;
    server_name 7bits.mooo.com;

    ssl_certificate     /etc/letsencrypt/live/7bits.mooo.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/7bits.mooo.com/privkey.pem;
    ssl_protocols       TLSv1.2 TLSv1.3;

    add_header Strict-Transport-Security "max-age=31536000" always;
    add_header X-Content-Type-Options    "nosniff" always;

    client_max_body_size 10M;         # 동기화 배치 상한 (05_API설계서 §3)

    location /api/ {
        proxy_pass         http://127.0.0.1:8080;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }
}
server {
    listen 80;
    server_name 7bits.mooo.com;
    return 301 https://$host$request_uri;
}
```
